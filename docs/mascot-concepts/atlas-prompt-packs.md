# Atlas Mascot Prompt Packs

Copy-paste prompt packs for external image generation, grounded in the Atlas creature bible.

Recommended use:

1. start with silhouette exploration
2. pick 2-3 strong directions
3. run portrait exploration on the winners
4. simplify into sticker/icon form
5. adapt into pixel minis last

## Global style anchor

Use this as a reusable prefix when needed:

```text
Create premium collectible-creature concept art for a polished iOS app called Atlas. The app visual language is calm, premium, blue-toned, and glassy, with navy, cobalt, pearl, ice blue, and subtle glow accents. The creature should feel like a guardian companion, not a childish toy, not a horror monster, and not a direct Pokemon copy. Prioritize silhouette clarity, chest-centered identity markers, and forms that can later be simplified into icons and tiny pixel sprites.
```

## Aetherion line

Evolution names:

- Cindlet
- Voltflare
- Aetherion

### Aetherion silhouette exploration

```text
Create a creature silhouette exploration sheet for a three-stage guardian evolution line for a premium iOS app called Atlas.

Line name: Aetherion line
Forms: Cindlet, Voltflare, Aetherion
Species concept: storm-forged drake guardian
Core fantasy: starts compressed and underdeveloped, evolves into sleek celestial thunder-dragon dominance

Non-negotiable traits across all 3 forms:
- glowing chest core
- horned drake head silhouette
- forward-leaning stance
- dark cool-toned body language

Form goals:
- Cindlet: compact body, oversized forearms, tiny wing buds, large head, obvious contained potential
- Voltflare: longer athletic limbs, sharper horns, active wings, diagonal speed silhouette
- Aetherion: sleek legendary body, long ceremonial wings, atlas-ring halo motif, noble mythic presence

Style:
- black-and-white silhouette sheet
- 6-9 variations per form
- premium game concept art presentation
- clear shape language
- no fine detail, no color rendering

Avoid:
- bulky western dragon
- cute chibi baby dragon
- demonic monster
- direct Charizard copy
- overdesigned armor
```

### Aetherion portrait exploration

```text
Create a polished character concept sheet for the final selected Aetherion evolution line for Atlas, a premium iOS companion system.

Show 3 evolved forms on one sheet:
1. Cindlet
2. Voltflare
3. Aetherion

Art direction:
- polished 2D digital illustration
- premium mobile-game creature art
- soft cel shading
- clean silhouette edges
- subtle painterly finish
- 3/4 view character presentation

Visual identity:
- storm-forged drake guardian
- obsidian navy and midnight blue body
- luminous electric-blue energy accents
- glowing ember-gold chest core
- horned head
- sleek ceremonial wings in final form
- atlas-ring halo motif in final form

Emotional read:
- Cindlet: scrappy, curious, contained power
- Voltflare: disciplined, fast, rising force
- Aetherion: noble, calm, mythic thunder guardian

Important:
- feels original, not a Pokemon clone
- premium, aspirational, not childish
- anatomy must remain readable for future sticker and pixel adaptations

Avoid:
- red fire-dragon palette
- aggressive evil expression
- bulky bodybuilder dragon proportions
- noisy fantasy armor
- cluttered background
```

### Aetherion sticker / icon simplification

```text
Create a sticker and app-icon adaptation sheet for the Aetherion line from Atlas.

Show Cindlet, Voltflare, and Aetherion as simplified front-facing or near-front-facing mascot stickers.

Requirements:
- transparent or plain light background
- simplified shapes
- minimal line detail
- large readable eyes
- chest core remains the main identity marker
- each form instantly distinguishable at small mobile UI size
- premium and cute-adjacent, but not childish

Keep:
- horn silhouette
- chest glow
- drake identity
- cool navy / cobalt palette

Avoid:
- emoji style
- plush toy look
- generic game app icon look
- too much detail
```

### Aetherion pixel mini adaptation

```text
Create a pixel art sprite sheet for the Aetherion line from Atlas.

Show 3 creatures:
- Cindlet
- Voltflare
- Aetherion

For each creature, create:
- 1 idle sprite
- 1 happy / powered-up sprite

Style:
- premium retro-inspired pixel art
- readable on a modern iPhone widget
- tiny sprite scale
- clean silhouette first
- limited palette with 3-5 major color clusters

Must preserve:
- glowing chest core
- horned drake silhouette
- evolution progression from compact to sleek legendary
- cool navy / cobalt body with gold core accent

Avoid:
- muddy shading
- over-animation
- tiny unreadable details
- overly nostalgic 8-bit game UI framing
```
